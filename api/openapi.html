API платформы городской сети камер хранения (1.0.0)

Download OpenAPI specification:Download

OpenAPI-спецификация пользовательской части платформы городской сети камер хранения с возможностью доставки вещей между локациями. Спецификация покрывает сценарии поиска локаций, бронирования, продления хранения, оформления перемещения, оплаты и поддержки.

Locations

Поиск и отображение доступных локаций

Получение списка доступных вариантов хранения

Возвращает предварительно доступные варианты хранения для экрана выбора локации. Используется список карточек доступных локаций с количеством доступных ячеек и минимальной стоимостью.
