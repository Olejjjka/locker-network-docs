# Документация городской сети камер хранения

Учебный проект Т-Академии: платформа хранения вещей и их перемещения между локациями.

- [Опубликованная документация](https://olejjjka.github.io/locker-network-docs/).
- [Карта артефактов](my-website/docs/artifact-map.md).

Сайт работает на существующем Docusaurus 3.10.1. Исходники находятся в `my-website/`.

## Локальная работа

Рекомендуется Node.js 22, как в CI.

```sh
cd my-website
npm ci
npm run check
npm run build
npm run check:links
npm run serve
```

Проверки включают OpenAPI, AsyncAPI, структуру XML, ссылки, ресурсы и якоря собранных страниц. Проверка XML не заменяет семантическую проверку BPMN/DMN. Отображение PlantUML и draw.io дополнительно проверяется в браузере, поскольку зависит от внешних сервисов.

## Работа с документацией

Работайте в отдельной ветке и открывайте PR в `main`. Workflow `Validate documentation` проверяет PR без публикации. Публикация запускается после push в `main`.

Шаблоны будущих документов не считаются завершёнными артефактами проекта.
